# کپتیو | Captio

یک استودیوی زیرنویس فارسی برای اندروید. ویدیو را انتخاب کنید، صدای آن را جدا کنید و با Whisper زیرنویس زمان‌دار بسازید؛ سپس متن و زمان هر بخش و ظاهر آن را تغییر دهید و ویدیوی MP4 یا فایل SRT بگیرید.

## ساخت APK در GitHub
ابتدا فایل گردش کار را در شاخهٔ پیش‌فرض مخزن قرار دهید؛ GitHub برای نمایش اجرای دستی به این کار نیاز دارد. سپس از تب **Actions**، گردش کار **Build and release Android APK** را انتخاب و **Run workflow** را اجرا کنید (و شاخهٔ مورد نظر را انتخاب کنید). پس از موفقیت، فایل `captio.apk` در بخش Releases قرار می‌گیرد. در تنظیمات مخزن باید اجازهٔ نوشتن به GitHub Actions داده شده باشد. این نسخه با کلید دیباگ ساخته‌شده در CI امضا می‌شود و برای انتشار رسمی یا به‌روزرسانی قابل اعتماد باید امضای اختصاصی و پایدار تنظیم شود. حداقل اندروید ۸ است.

برای ساخت محلی: JDK 17، Android SDK 35 و Gradle 8.9 لازم است؛ `gradle testDebugUnitTest assembleRelease` را اجرا کنید.

## رونویسی و حریم خصوصی
برای ساخت خودکار، اتصال اینترنت لازم است. کلید محدود GapGPT برای مدل `gapgpt/whisper-1` در کد برنامه قرار داده شده است و کاربر نیازی به وارد کردن آن ندارد. برنامه درخواست سازگار با OpenAI را به `https://api.gapgpt.app/v1/audio/transcriptions` می‌فرستد و انتظار پاسخ `verbose_json` با زمان‌بندی بخش‌ها را دارد. این سازگاری باید با سرویس واقعی بررسی شود. اگر سرویس زمان‌بندی کلمات را نیز برگرداند، استایل بنفش کلمهٔ جاری را برجسته می‌کند؛ در غیر این صورت کل بخش نمایش داده می‌شود. هنگام ویرایش یا تقسیم یک بخش، زمان‌بندی کلمه‌های آن پاک می‌شود و به نمایش بخش برمی‌گردد.

صدا در دستگاه به فایل صوتی تبدیل می‌شود و فقط فایل صوتی (نه ویدیو) برای سرویس ارسال می‌شود. استفاده از API ممکن است هزینه داشته باشد و مشمول سیاست‌های GapGPT است. کلید عمداً در مخزن و APK تعبیه شده است و هر کسی که به کد یا فایل APK دسترسی دارد می‌تواند آن را استخراج کند؛ خصوصی بودن مخزن از کلید موجود در APK محافظت نمی‌کند. برای انتشار عمومی از یک سرور امن با احراز هویت، محدودیت استفاده و مدیریت اشتراک استفاده کنید. سقف فایل صوتی ارسالی ۲۵ مگابایت است؛ فایل‌های طولانی را پیش از ورود کوتاه کنید. ویرایش دستی و خروجی بدون کلید هم ممکن است.

فایل‌های خروجی با انتخاب محل ذخیره توسط کاربر نوشته می‌شوند. پروژه‌ها فعلاً پس از بستن برنامه ذخیره نمی‌شوند. پیش‌نمایش ظاهر زیرنویس تقریبی است و ممکن است با خروجی روی بعضی دستگاه‌ها کمی تفاوت داشته باشد. خروجی ویدیو به پشتیبانی رمزگذار دستگاه وابسته است.

## محدودهٔ نسخه
انتخاب زبان و نشانه‌گذاری، ویرایش متن و زمان، افزودن، تقسیم و حذف بخش، چهار سبک، اندازه و جایگاه زیرنویس، خط زمان تصویری با جست‌وجو، خروجی SRT و MP4. برجسته‌سازی کلمه‌ای به دریافت زمان‌بندی کلمات از سرویس بستگی دارد. ترجمه، حذف نویز، برش ویدیو، مدیریت اشتراک و رونویسی آفلاین در این نسخه پیاده‌سازی نشده‌اند.

ایدهٔ محصول با بررسی [صفحهٔ Captiono در Google Play](https://play.google.com/store/apps/details?id=ai.captiono.app) شکل گرفته است؛ این پروژه وابسته به Captiono نیست.
